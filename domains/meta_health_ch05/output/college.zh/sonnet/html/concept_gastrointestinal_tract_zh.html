消化道

定义。 消化道(胃肠道)是一条从口腔到肛门、长约 $9\ \text{m}$ 的连续管道,依次为口腔、咽、食管、胃、小肠(十二指肠、空肠、回肠)和大肠。肝脏和胰腺不是管道本身,而是附属消化器官:它们通过导管把胆汁和胰液排入十二指肠。消化道的任务有两项:一是消化,把食物分解成可吸收的小分子;二是吸收,把营养物质、水和电解质送入血液或淋巴。

各段分工如下:

| 部位 | 主要功能 | |---|---| | 口腔 | 咀嚼;唾液淀粉酶开始分解淀粉 | | 食管 | 蠕动推送食团,约 $10\text{–}15$ 秒到达胃 | | 胃 | 盐酸($\text{pH}\approx 1.5\text{–}3.5$)与胃蛋白酶初步消化蛋白质 | | 小肠 | 消化的主要场所,也是吸收的主要场所;绒毛和微绒毛使吸收面积大大增加 | | 大肠 | 吸收水和电解质,形成粪便,容纳肠道菌群 | | 肝脏 | 分泌胆汁,帮助脂肪乳化 | | 胰腺 | 分泌胰淀粉酶、胰蛋白酶、胰脂肪酶和碳酸氢盐 |

例题。 一份午餐含 $60\ \text{g}$ 碳水化合物、$30\ \text{g}$ 蛋白质、$20\ \text{g}$ 脂肪。请追踪各营养素的消化位置,并估算能量。

  • 碳水化合物: 口腔中唾液淀粉酶开始分解淀粉;进入胃后,胃酸使该酶失活;在小肠中由胰淀粉酶继续分解,最终由小肠刷状缘的酶变成葡萄糖并被吸收。
  • 蛋白质: 胃蛋白酶先将其切成大的肽段,小肠中胰蛋白酶等进一步分解为氨基酸和短肽。
  • 脂肪: 胃里仅有少量消化。到十二指肠后,胆汁将脂肪乳化成小滴,胰脂肪酶再将其分解为脂肪酸和单酸甘油酯。
  • 能量: 按常用的能量换算系数(碳水化合物和蛋白质约 $4\ \text{kcal/g}$,脂肪约 $9\ \text{kcal/g}$):
    • $$60\times4+30\times4+20\times9=240+120+180=540\ \text{kcal}$$

    问题解决应用。 把部位与功能对应起来,就能推断症状的来源。

    情境一: 一位患者做了胆囊切除术,吃了油腻食物后容易腹泻、大便油腻。分析:肝脏仍分泌胆汁,但胆囊不再浓缩和储存,胆汁无法在进食时集中排出,脂肪乳化不充分,未消化的脂肪进入大肠,引起脂肪泻。因此建议少量多餐、减少单次脂肪摄入。

    情境二: 乳糖不耐受者喝牛奶后腹胀。分析:小肠刷状缘乳糖酶不足,乳糖不能被分解吸收,进入大肠后被细菌发酵产气,并通过渗透作用把水拉入肠腔。判断时应注意,问题出在小肠的消化环节,而不是胃酸或胰腺。

    情境三: 严重胰腺炎或胰腺切除后,胰酶分泌不足,三大营养素都难以消化,尤其是脂肪,常需口服胰酶制剂。

    解题思路:先问"食物此刻走到了哪一段",再问"这一段缺少了什么酶、胆汁或吸收面积",症状的原因通常就清楚了。
